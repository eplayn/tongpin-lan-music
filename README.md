# 同频 · Tongpin LAN Music

在局域网内共享系统声音，让音源本机和多个网页听者按照共同时间线播放。

基于 Node.js、Web Audio 和流式 HTTP，运行时无需 npm 第三方依赖。服务器转发 PCM，不二次编码，不将实时声音写入磁盘。当前版本 **3.2.3**。

## 功能

- 虚拟声卡作为系统音源，源端也通过网页同步回放。
- Android、iPhone、iPad 和桌面浏览器加入共听。
- 主持接管、全体/单个听者音量控制、本机输出设备选择。
- 动态共同缓冲：1000ms 起步，允许范围 100～2000ms，不保证能稳定达到 100ms。
- 500ms 内稳定优先：稳定至少30秒且余量足够才降低20ms，依据近一分钟有效反馈保留安全余量，不把400ms写死为目标。
- 听者掉线独立重连并撤掉该设备的延迟记录；音源彻底断流时无法继续产生声音。

## Windows 快速开始

1. 安装 [Node.js](https://nodejs.org/) 22 或更高版本，下载或克隆本仓库。
2. 双击 `Start-Live.cmd`，生成本机证书并打开 `http://127.0.0.1:8877/live/`。
3. 需要局域网访问时运行 `Allow-LAN.cmd`，确认管理员提示。规则仅开放专用/域网络的本地子网；可信家庭网络需设为“专用”。
4. 其他设备使用启动窗口或网页显示的地址，点击加入共听。
5. 关闭用 `Stop-Music.cmd`；关闭网页不会关闭服务器。

不需要执行 npm install。命令行可使用 `node server.mjs --port 8877`，但不会自动生成 HTTPS 证书。非 Windows 主机可运行 Node 服务，Windows 启动及防火墙脚本不适用；未做非 Windows 主机实机验证。

## 服务器本机共享声音

从厂商安装 [VB-CABLE](https://vb-audio.com/Cable/) 并按要求重启。使用支持音频输出选择的 Chrome/Edge。本仓库不包含第三方驱动。

1. 音乐应用输出选 **CABLE Input**，开始播放。应用自己的输出设置优先于系统默认输出。
2. 网页点击 **加入共听**，读取设备并允许音频输入权限。
3. 音源输入选 **CABLE Output**，回放输出明确选 **真实扬声器/耳机**。
4. 点击 **接管主持**，再点击系统音源区域的 **开始共享**。仅加入或接管不会开始采集。
5. 确认网页本机音量、主持总音量、听者音量和系统音量均未静音。

声音路径：音乐应用 → CABLE Input → CABLE Output → 音源网页 → 服务器 → 各听者网页 → 真实扬声器。

本机使用 `127.0.0.1` 不需要信任自签名证书。不要把网页回放再送进 CABLE，否则会回授。

## 其他电脑供源与 HTTPS

- 仅收听：使用 HTTP 地址即可，无需虚拟声卡或证书。
- 远程供源：使用 `https://服务器IP:8878/live/`，必须是浏览器认可的安全上下文。
- 首次启动生成 `Tongpin-LAN.cer`，核对 `data/https-info.json` 指纹后，将公钥证书导入远程供源电脑的受信任根证书存储。绕过证书警告不能替代正确配置。
- 切换服务器电脑、新增 IP 或证书临近过期时会重建证书，需要重新信任。
- **不要分发 `data/https.pfx` 私钥。**
- Mac 音源需要对应虚拟声卡及支持独立输出选择的浏览器；代码兼容路径已提供，但没有 Mac 实机验证。

## 同步原理与限制

客户端通过多轮时钟往返估计服务器时间。音源按采样数生成连续时间戳，服务器为每块 PCM 固定共同播放起止时刻。听者按该映射安排播放并微调漂移；调整共同缓冲不会重建时间线。

时间伸缩通过网页播放速率实现，可能产生轻微音高变化。系统报告的输出延迟不等于声学实测，蓝牙、AirPlay 和硬件差异可能需要本机补偿。不能承诺所有设备扬声器物理上绝对同步。

移动浏览器切后台或锁屏可能暂停音频、冻结页面；Worker、媒体控制和自动重连不能绕过系统限制。页面恢复后追随当前进度，不补播离线内容。

设备标识按浏览器及网站地址保存，不是硬件序列号。换浏览器、服务器地址或清理站点数据可能得到新标识。设备真实名称通过主机名或局域网反查尽力获取，无法保证所有设备都提供真实名称。

## 开发与验证

```sh
node --test test/*.test.mjs
```

55项检查覆盖时间映射连续性、动态收敛、断线隔离、设备身份、音量权限、协议及 HTTP 接口，并保留基础文件播放器核心回归测试。Windows 可先运行 `Prepare-HTTPS.ps1`，让 HTTP 集成测试同时覆盖 HTTPS。

真实 CABLE 与双浏览器播放已在开发机器验证；模拟结果和软件时差不是声学同步测量。

- `lib/`：房间、音频转发、自适应缓冲控制。
- `public/live/`：网页采集、播放和界面。
- `public/sync-core.mjs`：校时核心。
- `test/`：Node 内置测试，无外部测试依赖。

保留旧文件播放内部实现供回归；当前入口重定向到 `/live/`，上传及转码入口关闭。无需 FFmpeg。

## 安全与隐私

适用于可信局域网，不要直接暴露到公网。房间没有用户账号或入场密码；能访问服务器的人可以加入并接管主持。HTTP 收听未加密，HTTPS 才提供传输加密。房间状态包含设备名称、浏览器信息和播放状态。

运行数据、日志、证书、驱动及私人音乐不在仓库中。报告问题前请清除日志中的设备名、地址和凭据。
